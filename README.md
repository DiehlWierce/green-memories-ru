# Green Memories — русификатор (v1.5.0)

Русский перевод GBA-игры **Green Memories** (Tengukaze Studio). Основа — релиз v1.5.0 (`save_sram`) с [itch.io](https://tengukaze.itch.io/). Русский язык заменяет португальский слот, английский остаётся как был.

## Что переведено
- весь текст: диалоги, заставки, интерфейс, названия мест;
- туториал (8 страниц), экран управления, меню паузы, вкладки (Статус, Инвентарь, Карта, Миссия, Дневник, Система), подписи категорий инвентаря, лавки, экран Game Over;
- титры не переводились.

В меню выбора языка пункт «русский» стоит на месте португальского.

## Что скачать
Есть два варианта, результат одинаковый:
- **Готовая игра** — `Green_Memories_v1.5.0_RU.gba` в разделе [Releases](../../releases). Просто запускайте в эмуляторе или на флешкартридже.
- **IPS-патч** — `Green_Memories_v1.5.0_RU.ips` в корне репозитория и в Releases. Нужен, если хотите собрать ром сами из оригинала.

## Как применить патч
Файл патча — `Green_Memories_v1.5.0_RU.ips`. Наложите его на оригинальный ром `green_memories_v1.5.0-save_sram.gba` (любой IPS-патчер, например Floating IPS или онлайн-патчер).

Контрольные суммы оригинала:
- MD5: `35d1250ba3dec253a2975b33d7a6c6d5`
- SHA-1: `99e8259f917ac1f745825e8bc04a7885100aa9f9`

Проверено в mGBA.

## Исходники
- `translation/` — переведённые строки;
- `tools/` — скрипты сборки (Python 3, нужны `numpy`, `Pillow`). Сам ром в репозиторий не входит, готовый ром лежит в Releases.

## Права
Игра принадлежит её авторам (Tengukaze Studio). В репозитории только патч и переводы; готовая сборка выложена отдельно в Releases. Если правообладатели попросят убрать её, она будет удалена.
